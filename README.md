# Vfm Ohasap

一种物理沙盒 —— 面向物理教学与自主探索的 2D 力学模拟器。

在画布上随手摆放小球、木块、弹簧、滑轮与斜面，施加力、设定初速度，然后观察牛顿力学如何接管一切。支持实时受力分析、运动轨迹、逻辑触发事件，以及一个能自动列式的符号运算模式。

## ✨ 功能特性

### 🧱 物体与约束
- **基础刚体**：小球、木块、木板，可调质量、密度、摩擦系数、恢复系数
- **弹簧与绳子**：胡克定律（劲度系数 k）、弹性限度（超过后绳子断裂）、自由端旋转
- **杆与环**：刚性杆连接，环可沿杆滑动（带摩擦）
- **滑轮**：定滑轮 / 动滑轮，绳子可缠绕滑轮与斜面顶角
- **斜面**：直斜面、弧形斜面（四分之一圆弧轨道）
- **装水容器**：容器可漏水，支持管道与管道直径设置

### 🌊 水体模拟
- 一维浅水方程（Shallow Water Equations）数值解，60 列流体柱
- 实时水面波动、泡沫、气泡与水滴粒子
- 精确的浮力计算（基于物体浸没面积随水位动态变化）
- 容器运动（晃动、加速）会真实带动水体

### ⚔️ 精细切割
- 任意两点连线切割物体，一刀分成两半
- 切割后质量、面积、重心按几何重新计算
- 可选择保留哪一侧、切换保留部分、按比例舍弃

### 📊 分析工具
- **受力分析**：实时显示重力、支持力、摩擦力、弹簧力、张力、浮力等各分力矢量
- **运动轨迹**：记录并绘制物体运动路径
- **v-t 图像**：实时速度-时间曲线
- **显示状态**：标注物体的位置、速度、加速度等状态量

### 🔗 逻辑触发系统
- **触发条件**：经过一段时间 / 接触某物体 / 接触持续时间 / 第 N 次接触 / 物体消失……支持与（且）、或复合逻辑
- **触发动作**：施加外力、设置初速度、固定/解除固定、绑定/解除绑定、缠绕/解除缠绕、远程锁定
- 可以搭建"碰到底后弹飞""3 秒后释放"之类的连锁机关，用于演示物理过程

### 🧮 符号模式
- 以"极小 ~ 极大"五档定性描述未知量，按已知条件自动推导
- 自动列出运动学 / 动力学表达式（含 sin/cos、√、分数等），可直接查看推导结果
- 适合做题时快速验算受力与运动学关系

### 🎛 交互与全局
- 手绘式放置 + 拖拽、切割、橡皮擦、初速度 / 加速度赋予等多种模式
- 撤销点、场景快照恢复
- 可调重力加速度、风力 / 空气阻力
- 自适应物理子步（根据物体速度、弹簧刚度与杆曲率自动加密时间步），高速碰撞与硬约束也稳定

## 🔨 构建（Android）

当前 `app/` 收录 Android 端核心源码 `MainActivity.java`（`com.lie.acsm`，约 1.4 万行，物理引擎 + UI 全部集中在一个文件，零第三方依赖）。

> ⚠️ 配套的 `res/layout/main.xml` 暂未收录，自行编译需先补一个布局文件，其中须包含以下控件：
> `mainArea` / `canvasContainer` / `rightPanelContainer` / `rightToggleBtn`（FrameLayout），
> `timeLabel`（TextView）、`timeBar`（SeekBar）、
> `playBtn` / `resetBtn` / `restartBtn` / `btnNormal` / `btnVelocity` / `btnAccel` / `btnDraw` / `btnCut` / `btnErase` / `settingsBtn`（Button）、
> `tvCutPercent`（TextView），布局文件名需为 `main.xml`。
> 完整 Gradle 工程文件后续会补上，欢迎 Issue 催更。
